# Atlas Production

Single-file floor board for absenteeism, plan compliance, machining, and vendor parts. No server and no install.

Live site: https://iqbaladil039-oss.github.io/

The published copy is the repository [iqbaladil039-oss.github.io](https://github.com/iqbaladil039-oss/iqbaladil039-oss.github.io). This repository is the same board. Project Pages could not be switched on for `atlas-floor-board` from the connected GitHub account.

## View it

- Live: https://iqbaladil039-oss.github.io/
- Offline: download this folder and open `index.html`. Keep `pack.json` in the same folder. If the morning file does not load, use **Load pack** and choose `pack.json`.

## Edit the figures

1. Choose the date, shift, and flow.
2. Press **Edit figures**.
3. Change the numbers. The board updates immediately and the edits stay in this browser.
4. Press **Save pack** and replace `pack.json` with the downloaded file.
5. Commit that file on [iqbaladil039-oss.github.io](https://github.com/iqbaladil039-oss/iqbaladil039-oss.github.io) if the live site should show it. A browser that has not saved its own edits will load `pack.json`.

`Load pack` reads a `pack.json` you already saved. **Reset this slice** drops your edits for the date, shift, and flow on screen.

The 14-day charts stay on the generated history. Edited numbers apply to the selected day only.
