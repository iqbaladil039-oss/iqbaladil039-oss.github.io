# Atlas Production

Single-file floor board for absenteeism, plan compliance, machining, and vendor parts. No server and no install.

## View it

- On GitHub Pages, open the site URL.
- Offline, download this folder and open `index.html` in a browser. Keep `pack.json` in the same folder.

## Edit the figures

1. Choose the date, shift, and flow.
2. Press **Edit figures**.
3. Change the numbers. The board updates immediately and the edits stay in this browser.
4. Press **Save pack** and replace `pack.json` in this folder with the downloaded file.
5. Commit that file if you want the edited pack shared. On the next open, a browser that has not saved its own edits will load `pack.json`.

`Load pack` reads a `pack.json` you already saved. **Reset this slice** drops your edits for the date, shift, and flow on screen.

The 14-day charts stay on the generated history. Edited numbers apply to the selected day only.
